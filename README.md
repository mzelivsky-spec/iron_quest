Autor: Milan Želivský. Všechna práva vyhrazena, viz [LICENSE](LICENSE).

- `index.html` – celá appka
- `firestore.rules` – pravidla databáze (Firebase konzole → Firestore → Rules)
- `manifest.webmanifest`, `icon*` – instalace na plochu telefonu
